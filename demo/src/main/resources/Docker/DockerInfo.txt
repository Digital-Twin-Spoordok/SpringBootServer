Start beide containers opnieuw:
docker compose down
docker compose up -d --build

Controleer de status:
docker compose ps

Controleer de Spring Boot-logs:
docker logs springboot-server

Voor de springboot server:
docker exec -it springboot-server sh
Je bevindt je nu in de Linux-shell van je Spring Boot-container.

whoami

pwd
